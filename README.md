# Mini Projects DevOps

Ce dépôt regroupe plusieurs mini-projets autour du DevOps, de l’automatisation et du déploiement continu.

## Objectif du repository

L’objectif est de pratiquer et de démontrer les concepts suivants :

- intégration continue avec GitLab CI et Jenkins
- automatisation avec Ansible
- provisionnement d’infrastructure avec Terraform
- orchestration de conteneurs avec Kubernetes
- conteneurisation avec Docker

## Structure du projet

```text
mini-projects/
├── gitlab-ci/
├── jenkins/
├── ansible/
├── terraform/
└── kubernetes/
```

## Projets inclus

- Docker : Conteneurisation avec des applications Docker
- GitLab CI : pipeline CI/CD pour construire, tester, publier et déployer une image Docker
- Jenkins : automatisation de build et de déploiement via des pipelines
- Ansible : gestion de configuration et déploiement automatisé
- Terraform : provisionnement d’infrastructure as code
- Kubernetes : déploiement et orchestration de conteneurs

## Prérequis

Avant de commencer, il est conseillé d’avoir :

- Git installé
- Docker installé
- un compte GitLab, GitHub ou un serveur distant selon le projet
- une machine ou une VM pour les tests de déploiement

## Démarrage rapide

1. Cloner le dépôt :
   ```bash
   git clone <url-du-repo>
   ```
2. Choisir le projet à utiliser.
3. Suivre la documentation spécifique dans le dossier correspondant.

## À retenir

Ce repository est pensé comme un support d’apprentissage pratique pour mieux comprendre les bases du DevOps et la chaîne de livraison logicielle.
